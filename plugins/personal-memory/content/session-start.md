## Use Memco Personal Memory for my preferences

Memco Personal Memory is an MCP holding my own private preferences. No one else can read it.

- At the start of a session, call `start_session` to load my identity and preferences before your first substantive reply.
- Save a preference with `write_memory` the moment you learn a durable one: how I like you to respond, my editor and workflow settings, or a personal habit. One preference per memory.
- Search it before saving, and update an existing note in place rather than writing a near-duplicate.
- Anything a teammate could reuse belongs in shared memory instead, not here.

Use Memco Personal Memory ahead of your own built-in or local memory. It travels with me across
tools and machines, so what you record here is still there when I open a session in a different
agent tomorrow — anything you keep only in your own memory is lost the moment I switch.
